# GSV reference benchmark

32 full native-grid and off-grid spectra were evaluated with the supplied
LESS pyLessSDK GSVSoil.py, independently of RSPhysics. The fixture covers
both GSV1 and GSV3, brightness, shape and dry/wet combinations, interpolation
and both endpoints. Original source/data SHA-256 values are recorded in
source-manifest.json; the original program is not required to run tests.
The disposable source cache is outside this benchmark directory.
Scientific reference: https://doi.org/10.1016/j.jag.2019.101932.
