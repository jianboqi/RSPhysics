# L-MEB source and permissions

This Rust implementation adapts supplied MATLAB research code. Exact source
file hashes and reference entry paths are recorded in
`benchmarks/reference/lmeb/upstream-provenance.json`. Original reference files
are isolated in the disposable `.reference-cache/lmeb` directory.

The project maintainer confirmed permission to publish the supplied sources and
their adaptations on 2026-11-10. The supplied materials themselves contain no
explicit license file. `LicenseRef-User-Supplied-Research-Code` identifies these
component-specific terms; publication permission does not replace original
attribution or establish an upstream Apache-2.0 grant. Project-wide Apache-2.0
does not automatically relicense supplied code or datasets. Original MATLAB
source and station spreadsheets are not bundled with the runtime.
