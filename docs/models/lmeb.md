# L-MEB

L-MEB represents L-band microwave emission from soil and vegetation.[^lmeb]
The RSPhysics adaptation follows the supplied JPW MATLAB `tauw1i` soil-forward
path, fixed at **1.41 GHz**. It computes vertical/horizontal surface brightness
temperatures from soil moisture, texture, temperature, roughness, and vegetation.

## Implemented formulation

The selected path calculates effective soil temperature and the supplied Dobson
dielectric mixture, with the original frozen-soil and dry-sand branches. Complex
Fresnel coefficients provide soil power reflectivities, modified by empirical
roughness and polarization mixing. Directional vegetation opacity determines
the V/H canopy transmission. For polarization p:

```text
TB,p = (1 − ωp)(1 − γp)(1 + rp γp)Tc
       + [(1 − rp)Tg + Tsky rp γp]γp
```

The prescribed sky model uses sea-level altitude, 10 g/kg humidity, no rain,
and the separately supplied `sky_air_temperature_k`. This preserves the original
ordering: the sky calculation precedes the forward-mode effective-temperature
update. All brightness/physical temperatures use K; soil moisture is m³/m³,
texture fractions are 0–1, and bulk density is g/cm³.

## Python example

```python
import rsphysics as rsp

result = rsp.microwave.lmeb(soil_moisture=0.2, nadir_optical_depth=0.3)
tb_v = result['result']['brightness_temperature_v_k']
tb_h = result['result']['brightness_temperature_h_k']

table = rsp.parameter_grid('microwave.lmeb', {'soil_moisture': [0.1, 0.2, 0.3]})
batch = rsp.run_array('microwave.lmeb', table, shared_axes=True)
```

The full input contract is available through `rsp.describe('microwave.lmeb')`;
`parameters_for` defines the batch column order. Outputs also include effective
soil temperature, complex permittivity components, reflectivities, sky brightness,
canopy transmissions, and an 81-point 0–80° V/H angle experiment.

## Scope and verification

This is a specified historical forward parameterization, not the full SMOS
operational processor. Water/ice surfaces, saline water, the high-frequency Wang
branch, inversion, and generic coupling are excluded. The original water-surface
path references an unassigned `tg`; it is not silently repaired or exposed.
The dry-sand dielectric loss sign is retained and documented rather than
substituting the convention used by other RSPhysics optical tools.

32 cases and their complete polarization curves were generated by MATLAB R2026a
using unchanged scientific functions, including frozen soil, dry sand, bare soil,
and nadir. Fixtures and provenance are in the [reference directory](../../benchmarks/reference/lmeb).
Implementation agreement does not establish observational accuracy.
