# ADR 0004: Apache original code and additional SMAC permission

Date: 2026-11-10. Status: original-code license adopted; additional SMAC permission pending.

The owner selected Apache-2.0, retained the six-model package, and plans to ask
SMAC authors for permission. This supersedes ADR 0003's original-website GPL
choice while retaining public website source and library/product separation.

Original infrastructure, independently implemented models, and website code use
Apache-2.0. MIT model notices remain. The GPLv3 notice attached to the particular
SMAC source copy and all coefficient records remain until relevant rights holders
confirm additional Apache-2.0 code/data permission. Planned permission is not
recorded as already obtained.

A rights-contact statement will use the actual public repository's Issues;
it does not replace permission. No authorization email was sent, remote repository
created, or PyPI/website release performed by this decision.

See [license scope](../licensing.md) and the
[SMAC inquiry draft](../smac-authorization-request.md).
