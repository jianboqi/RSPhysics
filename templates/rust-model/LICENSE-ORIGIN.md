# Original source and data provenance

This template contains no third-party model code or coefficient data.

Replace this record when creating a model. Record the original version/commit,
source, authors, license, modifications, data permissions, and file SHA-256
values. Unverified permissions must be resolved before official distribution.

Original template code is Apache-2.0. `UNSET` in the model manifest is a placeholder
for the new model's source license, not permission to distribute third-party code
or data.
