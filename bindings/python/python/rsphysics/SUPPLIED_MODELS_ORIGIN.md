# Supplied GORT-GPP and L-MEB source permissions

These local integrations adapt supplied MATLAB research source. L-MEB attributes
the original routines to Jean-Pierre Wigneron (2001–2007). GORT-GPP follows the
supplied Main4PSN research workflow; complete source authorship remains to be
confirmed. Scientific context includes Wu et al. (2021),
https://doi.org/10.1016/j.agrformet.2021.108618, and Wigneron et al. (2007),
https://doi.org/10.1016/j.rse.2006.10.014.

The project maintainer confirmed permission to publish the supplied sources and
their adaptations on 2026-11-10. No explicit license file was found in the supplied
source sets. LicenseRef-User-Supplied-Research-Code identifies these component
terms. Original attribution is retained; project-wide Apache-2.0 does not
automatically relicense supplied code or datasets or establish an upstream
Apache-2.0 grant.

The package excludes original MATLAB installations, original source archives,
station spreadsheets, and supplied papers. Exact file checksums and original
numerical fixtures remain in benchmarks/reference/{gort-gpp,lmeb} in source.
